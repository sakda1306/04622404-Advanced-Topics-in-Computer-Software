# ผู้จัดการโครงการไอที (IT Project Manager)

## Role description

วางแผนและควบคุมโครงการ IT ให้เสร็จตามเวลา งบประมาณ และขอบเขต ประสานงานระหว่างทีมเทคนิคและผู้เกี่ยวข้อง

งานที่ทำเป็นประจำ: วางแผนงานและ sprint, ติดตามความคืบหน้า, จัดการความเสี่ยงและงบ, ประชุมกับลูกค้าหรือผู้บริหาร และแก้ปัญหาในทีม

ระดับตำแหน่ง: มักต้องมีประสบการณ์ทำงานด้าน IT มาก่อน 2-3 ปี เด็กจบใหม่มักเริ่มจากตำแหน่งใกล้เคียงก่อน

ทักษะด้านบุคคลที่สำคัญ: ภาวะผู้นำ, การสื่อสาร, การจัดระเบียบงาน, การบริหารเวลา, การเจรจาต่อรอง

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Project management (การบริหารโครงการ): ฝึกให้ถึงระดับใช้งานได้จริง
2. Agile / Scrum: ฝึกให้ถึงระดับใช้งานได้จริง
3. Stakeholder management (การบริหารผู้มีส่วนได้ส่วนเสีย): ฝึกให้ถึงระดับใช้งานได้จริง
4. Software development life cycle (วงจรการพัฒนาซอฟต์แวร์ (SDLC)): ฝึกให้ถึงระดับพื้นฐาน
5. Risk management and compliance (การบริหารความเสี่ยงและการปฏิบัติตามข้อกำหนด): ฝึกให้ถึงระดับพื้นฐาน
6. Budget management (การบริหารงบประมาณ): ฝึกให้ถึงระดับพื้นฐาน
7. Technical documentation (การเขียนเอกสารทางเทคนิค): ฝึกให้ถึงระดับพื้นฐาน
8. ทำโปรเจกต์ฝึกหัด: รับบทผู้จัดการโครงการในงานกลุ่มหรือโครงงาน ทำ project plan, backlog และ risk register แล้วสรุปบทเรียนหลังจบโครงการ

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): PMP / PRINCE2 certification, Requirements gathering and analysis, Bug tracking (Jira), Vendor management, SQL, Programming fundamentals
