# วิศวกร DevOps (DevOps Engineer)

## Role description

ทำให้การพัฒนาและ deploy ซอฟต์แวร์รวดเร็วและเสถียร ดูแล pipeline อัตโนมัติ โครงสร้างพื้นฐาน และการ monitor ระบบ

งานที่ทำเป็นประจำ: ดูแล CI/CD pipeline, จัดการ container และ cloud, ตั้งค่า monitoring และ alert และช่วยแก้ปัญหาเมื่อระบบล่ม

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การสื่อสาร, การทำงานเป็นทีม, การแก้ปัญหา

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Linux: ฝึกให้ถึงระดับใช้งานได้จริง
2. อย่างน้อยหนึ่งอย่างจาก AWS, Microsoft Azure, Google Cloud: ฝึกให้ถึงระดับใช้งานได้จริง
3. Docker / containers (Docker และคอนเทนเนอร์): ฝึกให้ถึงระดับใช้งานได้จริง
4. CI/CD: ฝึกให้ถึงระดับใช้งานได้จริง
5. อย่างน้อยหนึ่งอย่างจาก Python, Shell scripting (Bash/PowerShell): ฝึกให้ถึงระดับใช้งานได้จริง
6. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับใช้งานได้จริง
7. Monitoring and logging (การเฝ้าระวังและบันทึกระบบ): ฝึกให้ถึงระดับพื้นฐาน
8. ทำโปรเจกต์ฝึกหัด: ตั้ง CI/CD ด้วย GitHub Actions ที่ build Docker image ทดสอบ และ deploy แอปขึ้น cloud อัตโนมัติ พร้อมหน้า monitoring

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Kubernetes, Infrastructure as code (Terraform), Automation, Cybersecurity, Windows Server, Software deployment and release, Computer networking
