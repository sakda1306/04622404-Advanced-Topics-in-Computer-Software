# นักพัฒนาแบ็กเอนด์ (Backend Developer)

## Role description

พัฒนาระบบฝั่งเซิร์ฟเวอร์ ฐานข้อมูล และ API ที่แอปหรือเว็บเรียกใช้ ดูแลให้ระบบถูกต้อง ปลอดภัย และรองรับผู้ใช้จำนวนมาก

งานที่ทำเป็นประจำ: ออกแบบ API และตารางฐานข้อมูล, เขียน business logic, จัดการสิทธิ์ผู้ใช้, ดู log และแก้ปัญหาระบบที่ใช้งานจริง

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การแก้ปัญหา, การคิดวิเคราะห์, การทำงานเป็นทีม, การสื่อสาร

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. อย่างน้อยหนึ่งอย่างจาก Python, Java, Node.js, PHP, .NET, Ruby: ฝึกให้ถึงระดับใช้งานได้จริง
2. SQL: ฝึกให้ถึงระดับใช้งานได้จริง
3. REST API design (การออกแบบ REST API): ฝึกให้ถึงระดับใช้งานได้จริง
4. Database design (การออกแบบฐานข้อมูล): ฝึกให้ถึงระดับพื้นฐาน
5. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับพื้นฐาน
6. Linux: ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: สร้าง REST API สำหรับระบบจองหรือร้านค้า มีการ login, เก็บข้อมูลใน PostgreSQL หรือ MySQL และรันใน Docker

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Docker / containers, Caching (Redis, Memcached), NoSQL (MongoDB etc.), Microservices, Message queues (Kafka, RabbitMQ), Unit and integration testing, Software architecture / system design, Web servers (Nginx, Apache), PostgreSQL
