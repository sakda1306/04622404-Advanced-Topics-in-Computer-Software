# นักวิเคราะห์ข้อมูล (Data Analyst)

## Role description

วิเคราะห์ข้อมูลเพื่อตอบคำถามทางธุรกิจ ทำความสะอาดข้อมูล สร้างรายงานและกราฟที่ผู้บริหารเข้าใจได้

งานที่ทำเป็นประจำ: ดึงข้อมูลด้วย SQL, ทำความสะอาดข้อมูลใน Excel หรือ Python, สร้าง dashboard และนำเสนอผลวิเคราะห์ให้ทีม

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การคิดวิเคราะห์, การสื่อสาร, ทักษะการนำเสนอ, ความละเอียดรอบคอบ

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. SQL: ฝึกให้ถึงระดับใช้งานได้จริง
2. Microsoft Excel / spreadsheets (Microsoft Excel / สเปรดชีต): ฝึกให้ถึงระดับใช้งานได้จริง
3. Data visualization (การนำเสนอข้อมูลด้วยภาพ): ฝึกให้ถึงระดับใช้งานได้จริง
4. อย่างน้อยหนึ่งอย่างจาก Tableau, Power BI: ฝึกให้ถึงระดับพื้นฐาน
5. Statistics (สถิติ): ฝึกให้ถึงระดับพื้นฐาน
6. Data cleaning (การทำความสะอาดข้อมูล): ฝึกให้ถึงระดับใช้งานได้จริง
7. ทำโปรเจกต์ฝึกหัด: หา dataset สาธารณะ (เช่น จาก data.go.th) ทำความสะอาด วิเคราะห์ และสร้าง dashboard ใน Power BI หรือ Tableau พร้อมสรุปข้อค้นพบ

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Python, pandas / NumPy, Business metrics and KPIs, Business reporting, Data analysis, Mathematics (linear algebra, calculus)
