# นักพัฒนาฟูลสแตก (Full-stack Developer)

## Role description

พัฒนาได้ทั้งฝั่งหน้าเว็บและหลังบ้าน รับผิดชอบฟีเจอร์ได้ครบตั้งแต่หน้าจอจนถึงฐานข้อมูลและการ deploy

งานที่ทำเป็นประจำ: ทำฟีเจอร์ตั้งแต่ UI ไปจนถึง API และฐานข้อมูล, แก้บั๊กข้ามทั้งสองฝั่ง และช่วยดูแลการ deploy

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การสื่อสาร, การทำงานเป็นทีม, การปรับตัวและเรียนรู้อย่างต่อเนื่อง, การแก้ปัญหา

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. JavaScript: ฝึกให้ถึงระดับใช้งานได้จริง
2. อย่างน้อยหนึ่งอย่างจาก Node.js, Python, Java, PHP, .NET, Ruby: ฝึกให้ถึงระดับใช้งานได้จริง
3. HTML: ฝึกให้ถึงระดับใช้งานได้จริง
4. CSS: ฝึกให้ถึงระดับใช้งานได้จริง
5. อย่างน้อยหนึ่งอย่างจาก React, Angular, Vue.js: ฝึกให้ถึงระดับใช้งานได้จริง
6. SQL: ฝึกให้ถึงระดับใช้งานได้จริง
7. REST API design (การออกแบบ REST API): ฝึกให้ถึงระดับใช้งานได้จริง
8. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับพื้นฐาน
9. ทำโปรเจกต์ฝึกหัด: สร้างเว็บแอปครบวงจร (เช่น ระบบโพสต์และคอมเมนต์) ที่มี frontend, backend, ฐานข้อมูล, ระบบ login และ deploy ขึ้น cloud

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): TypeScript, Docker / containers, Software deployment and release, NoSQL (MongoDB etc.), Caching (Redis, Memcached), Linux, Software architecture / system design, UI design
