# ผู้ดูแลระบบฐานข้อมูล (Database Administrator)

## Role description

ดูแลฐานข้อมูลขององค์กรให้ปลอดภัย พร้อมใช้งาน สำรองข้อมูลได้ และทำงานเร็ว

งานที่ทำเป็นประจำ: ติดตั้งและตั้งค่าฐานข้อมูล, สำรองและกู้คืนข้อมูล, ปรับแต่ง query ที่ช้า, จัดการสิทธิ์ผู้ใช้ และวางแผนการขยายระบบ

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การแก้ปัญหา, การคิดวิเคราะห์, การจัดระเบียบงาน, การสื่อสาร

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. SQL: ฝึกให้ถึงระดับใช้งานได้จริง
2. อย่างน้อยหนึ่งอย่างจาก MySQL, PostgreSQL, Microsoft SQL Server, Oracle Database: ฝึกให้ถึงระดับใช้งานได้จริง
3. Backup and disaster recovery (การสำรองและกู้คืนข้อมูล): ฝึกให้ถึงระดับใช้งานได้จริง
4. Database performance tuning (การปรับแต่งประสิทธิภาพฐานข้อมูล): ฝึกให้ถึงระดับพื้นฐาน
5. อย่างน้อยหนึ่งอย่างจาก Linux, Windows Server: ฝึกให้ถึงระดับพื้นฐาน
6. Database design (การออกแบบฐานข้อมูล): ฝึกให้ถึงระดับพื้นฐาน
7. Cybersecurity (ความมั่นคงปลอดภัยไซเบอร์): ฝึกให้ถึงระดับพื้นฐาน
8. ทำโปรเจกต์ฝึกหัด: ติดตั้ง PostgreSQL หรือ MySQL บน Linux ตั้งระบบ backup อัตโนมัติ ทดลองกู้คืน และปรับ query ที่ช้าด้วย index

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Shell scripting (Bash/PowerShell), Capacity planning, NoSQL (MongoDB etc.), Cloud computing, Big data (Spark, Hadoop)
