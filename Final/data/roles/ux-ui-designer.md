# นักออกแบบ UX/UI (UX/UI Designer)

## Role description

ออกแบบประสบการณ์และหน้าตาของแอปหรือเว็บให้ใช้งานง่าย ตรงความต้องการผู้ใช้ และสวยงาม

งานที่ทำเป็นประจำ: สัมภาษณ์และทดสอบกับผู้ใช้, ทำ wireframe และ prototype ใน Figma, ออกแบบ UI และส่งต่องานให้นักพัฒนา

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: ความคิดสร้างสรรค์, ความเข้าอกเข้าใจผู้อื่น, การสื่อสาร, การทำงานเป็นทีม, การคิดวิเคราะห์

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. UX design (การออกแบบประสบการณ์ผู้ใช้ (UX)): ฝึกให้ถึงระดับใช้งานได้จริง
2. UI design (การออกแบบส่วนติดต่อผู้ใช้ (UI)): ฝึกให้ถึงระดับใช้งานได้จริง
3. Figma / design tools (Figma และเครื่องมือออกแบบ): ฝึกให้ถึงระดับใช้งานได้จริง
4. Wireframing and prototyping (การทำ Wireframe และต้นแบบ): ฝึกให้ถึงระดับใช้งานได้จริง
5. User research (การวิจัยผู้ใช้): ฝึกให้ถึงระดับพื้นฐาน
6. Responsive design (การออกแบบเว็บแบบ Responsive): ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: เลือกแอปที่ใช้งานยาก ทำ user research กับผู้ใช้ 3-5 คน ออกแบบใหม่ใน Figma และทำ usability test เปรียบเทียบก่อนและหลัง

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Web accessibility, Mobile UI development, Graphic design, HTML, CSS, Web design principles
