# วิศวกรคลาวด์ (Cloud Engineer)

## Role description

ออกแบบ ติดตั้ง และดูแลระบบบน cloud เช่น AWS, Azure หรือ GCP ให้ปลอดภัย พร้อมใช้งาน และคุ้มค่า

งานที่ทำเป็นประจำ: สร้างและตั้งค่าเครื่อง เครือข่าย และสิทธิ์บน cloud, ย้ายระบบขึ้น cloud, ดูค่าใช้จ่าย และแก้ปัญหาการเชื่อมต่อ

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การทำงานเป็นทีม, การสื่อสาร, การแก้ปัญหา, การบริการลูกค้า

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Cloud computing (คลาวด์คอมพิวติ้ง): ฝึกให้ถึงระดับใช้งานได้จริง
2. อย่างน้อยหนึ่งอย่างจาก AWS, Microsoft Azure, Google Cloud: ฝึกให้ถึงระดับใช้งานได้จริง
3. Computer networking (เครือข่ายคอมพิวเตอร์): ฝึกให้ถึงระดับใช้งานได้จริง
4. Linux: ฝึกให้ถึงระดับใช้งานได้จริง
5. Software deployment and release (การนำซอฟต์แวร์ขึ้นใช้งานจริง): ฝึกให้ถึงระดับพื้นฐาน
6. Cybersecurity (ความมั่นคงปลอดภัยไซเบอร์): ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: deploy เว็บแอปบน AWS หรือ Azure โดยตั้งค่า network, security group และฐานข้อมูลเอง แล้วสรุปค่าใช้จ่ายต่อเดือน

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Docker / containers, Kubernetes, Infrastructure as code (Terraform), CI/CD, Software architecture / system design, Python
