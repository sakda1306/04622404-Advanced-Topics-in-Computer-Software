# วิศวกรประกันคุณภาพซอฟต์แวร์ (QA Engineer / Tester)

## Role description

ตรวจสอบคุณภาพซอฟต์แวร์ก่อนส่งถึงผู้ใช้ วางแผนการทดสอบ หาบั๊ก และช่วยทีมป้องกันปัญหาซ้ำ

งานที่ทำเป็นประจำ: เขียน test case, ทดสอบด้วยมือและด้วยสคริปต์อัตโนมัติ, รายงานบั๊กในระบบติดตาม และทดสอบซ้ำหลังแก้ไข

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: ความละเอียดรอบคอบ, การคิดเชิงวิพากษ์, การสื่อสาร, การจัดระเบียบงาน, การแก้ปัญหา

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Manual testing (การทดสอบซอฟต์แวร์แบบแมนนวล): ฝึกให้ถึงระดับใช้งานได้จริง
2. Regression testing (การทดสอบการถดถอย): ฝึกให้ถึงระดับใช้งานได้จริง
3. Bug tracking (Jira) (การติดตามบั๊ก (Jira)): ฝึกให้ถึงระดับใช้งานได้จริง
4. Test automation (Selenium etc.) (การทดสอบอัตโนมัติ): ฝึกให้ถึงระดับพื้นฐาน
5. Software development life cycle (วงจรการพัฒนาซอฟต์แวร์ (SDLC)): ฝึกให้ถึงระดับพื้นฐาน
6. SQL: ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: เลือกเว็บไซต์หนึ่งแห่ง เขียน test plan และ test case แล้วทำ automated test ด้วย Selenium หรือ Playwright พร้อมรายงานบั๊กที่พบ

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Performance and load testing, REST API design, Agile / Scrum, ISTQB certification, Unit and integration testing, Python, JavaScript, Vulnerability assessment / penetration testing, User research
