# ผู้ดูแลระบบเครือข่าย (Network Administrator)

## Role description

ดูแลระบบเครือข่ายขององค์กรให้เชื่อมต่อได้เสถียรและปลอดภัย ทั้ง LAN, WAN, firewall และอุปกรณ์เครือข่าย

งานที่ทำเป็นประจำ: ตั้งค่า router และ switch, จัดการ firewall, monitor เครือข่าย และแก้ปัญหาการเชื่อมต่อของผู้ใช้

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การแก้ปัญหา, การสื่อสาร

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Computer networking (เครือข่ายคอมพิวเตอร์): ฝึกให้ถึงระดับใช้งานได้จริง
2. TCP/IP, DNS, DHCP: ฝึกให้ถึงระดับใช้งานได้จริง
3. Routing and switching (การกำหนดเส้นทางและสวิตชิ่ง): ฝึกให้ถึงระดับใช้งานได้จริง
4. Technical troubleshooting (การแก้ไขปัญหาทางเทคนิค): ฝึกให้ถึงระดับใช้งานได้จริง
5. Firewalls (ไฟร์วอลล์): ฝึกให้ถึงระดับพื้นฐาน
6. LAN / WAN / Wi-Fi: ฝึกให้ถึงระดับพื้นฐาน
7. Monitoring and logging (การเฝ้าระวังและบันทึกระบบ): ฝึกให้ถึงระดับพื้นฐาน
8. ทำโปรเจกต์ฝึกหัด: จำลองเครือข่ายสำนักงานใน Cisco Packet Tracer ที่มี VLAN, routing และ firewall rule พร้อมทดสอบการเชื่อมต่อ

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Cisco (CCNA), CompTIA A+ / Network+, Active Directory, Authentication and access control, Windows Server, Linux, Network security
