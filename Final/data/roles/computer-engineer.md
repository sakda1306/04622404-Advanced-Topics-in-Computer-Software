# วิศวกรคอมพิวเตอร์ (Computer Engineer)

## Role description

ทำงานคาบเกี่ยวระหว่างฮาร์ดแวร์และซอฟต์แวร์ ออกแบบ ทดสอบ และแก้ปัญหาระบบคอมพิวเตอร์ อุปกรณ์ และเครือข่าย

งานที่ทำเป็นประจำ: เขียนโปรแกรมควบคุมอุปกรณ์, ทดสอบและแก้ปัญหาฮาร์ดแวร์, ดูแลเครือข่าย และทำเอกสารทางเทคนิค

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การแก้ปัญหา, การทำงานเป็นทีม, การบริหารเวลา, การสื่อสาร

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. อย่างน้อยหนึ่งอย่างจาก C, C++, Python, Java: ฝึกให้ถึงระดับใช้งานได้จริง
2. Computer architecture (สถาปัตยกรรมคอมพิวเตอร์): ฝึกให้ถึงระดับใช้งานได้จริง
3. Electronics and circuit design (อิเล็กทรอนิกส์และการออกแบบวงจร): ฝึกให้ถึงระดับพื้นฐาน
4. Computer networking (เครือข่ายคอมพิวเตอร์): ฝึกให้ถึงระดับพื้นฐาน
5. Debugging (การดีบักโปรแกรม): ฝึกให้ถึงระดับใช้งานได้จริง
6. Hardware installation and troubleshooting (การติดตั้งและแก้ไขปัญหาฮาร์ดแวร์): ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: ทำโปรเจกต์ IoT ด้วยบอร์ดอย่าง ESP32 หรือ Raspberry Pi ที่อ่านค่าเซนเซอร์และส่งข้อมูลผ่านเครือข่ายไปแสดงผล

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Embedded systems, IoT, Linux, Database design, API and system integration, Project management
