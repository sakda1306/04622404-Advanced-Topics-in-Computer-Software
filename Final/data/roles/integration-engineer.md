# วิศวกรเชื่อมต่อระบบ (Integration Engineer)

## Role description

เชื่อมระบบหลายระบบให้แลกเปลี่ยนข้อมูลกันได้ถูกต้อง เช่น เชื่อมระบบขาย ระบบบัญชี และระบบลูกค้าผ่าน API

งานที่ทำเป็นประจำ: อ่านเอกสาร API ของระบบต่าง ๆ, เขียนตัวเชื่อมและแปลงข้อมูล, ทดสอบการรับส่งข้อมูล และคุยกับผู้ใช้เพื่อเก็บ requirement

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การสื่อสาร, การจัดระเบียบงาน, การแก้ปัญหา, การทำงานได้ด้วยตนเองและมีแรงจูงใจ

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. API and system integration (การเชื่อมต่อระบบผ่าน API): ฝึกให้ถึงระดับใช้งานได้จริง
2. REST API design (การออกแบบ REST API): ฝึกให้ถึงระดับใช้งานได้จริง
3. อย่างน้อยหนึ่งอย่างจาก Python, JavaScript, Java: ฝึกให้ถึงระดับใช้งานได้จริง
4. JSON: ฝึกให้ถึงระดับใช้งานได้จริง
5. SQL: ฝึกให้ถึงระดับพื้นฐาน
6. Technical documentation (การเขียนเอกสารทางเทคนิค): ฝึกให้ถึงระดับพื้นฐาน
7. Requirements gathering and analysis (การเก็บและวิเคราะห์ความต้องการ): ฝึกให้ถึงระดับพื้นฐาน
8. ทำโปรเจกต์ฝึกหัด: เขียนสคริปต์ที่ดึงข้อมูลจาก API หนึ่ง แปลงรูปแบบ JSON แล้วส่งต่อเข้าอีกระบบ พร้อมจัดการ error และเขียนเอกสารการเชื่อมต่อ

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): SOAP / XML, Message queues (Kafka, RabbitMQ), MuleSoft / iPaaS, ETL / data pipelines, AWS, Software deployment and release, Manual testing, Cybersecurity
