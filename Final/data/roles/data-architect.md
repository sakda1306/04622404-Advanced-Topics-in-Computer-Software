# สถาปนิกข้อมูล (Data Architect)

## Role description

ออกแบบโครงสร้างข้อมูลระดับองค์กร กำหนดมาตรฐาน การจัดเก็บ และการกำกับดูแลข้อมูลให้ทุกระบบใช้ร่วมกันได้

งานที่ทำเป็นประจำ: ออกแบบ data model และ data warehouse, วางมาตรฐานและนโยบายข้อมูล, เลือกเทคโนโลยี และให้คำปรึกษาทีมข้อมูล

ระดับตำแหน่ง: เป็นตำแหน่งระดับอาวุโส มักต้องมีประสบการณ์ด้านข้อมูลหรือฐานข้อมูล 5 ปีขึ้นไป เด็กจบใหม่มักเริ่มจาก Data Engineer หรือ Database Administrator

ทักษะด้านบุคคลที่สำคัญ: การสื่อสาร, ภาวะผู้นำ, ทักษะการนำเสนอ, ความละเอียดรอบคอบ, ทักษะมนุษยสัมพันธ์

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Data modeling (การออกแบบแบบจำลองข้อมูล): ฝึกให้ถึงระดับคล่อง
2. Database design (การออกแบบฐานข้อมูล): ฝึกให้ถึงระดับคล่อง
3. SQL: ฝึกให้ถึงระดับคล่อง
4. Data governance and security (ธรรมาภิบาลข้อมูล): ฝึกให้ถึงระดับใช้งานได้จริง
5. Data warehousing (คลังข้อมูล (Data Warehouse)): ฝึกให้ถึงระดับใช้งานได้จริง
6. Cloud computing (คลาวด์คอมพิวติ้ง): ฝึกให้ถึงระดับใช้งานได้จริง
7. ทำโปรเจกต์ฝึกหัด: ออกแบบ data warehouse ของธุรกิจสมมติ ตั้งแต่ source systems จนถึง star schema พร้อมเอกสารมาตรฐานข้อมูลและ data governance

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Big data (Spark, Hadoop), ETL / data pipelines, NoSQL (MongoDB etc.), AWS, Data management, Business reporting
