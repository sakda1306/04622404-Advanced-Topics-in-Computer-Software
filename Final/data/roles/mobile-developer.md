# นักพัฒนาแอปพลิเคชันมือถือ (Mobile Developer)

## Role description

พัฒนาแอปบนมือถือ Android หรือ iOS ให้ใช้งานลื่นไหล เชื่อมต่อกับ API และผ่านเกณฑ์ของ app store

งานที่ทำเป็นประจำ: พัฒนาหน้าจอแอป, เชื่อมต่อ API, ทดสอบบนอุปกรณ์จริงหลายรุ่น, แก้ crash และเตรียมเวอร์ชันเพื่อส่งขึ้น store

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การแก้ปัญหา, ความคิดสร้างสรรค์, การทำงานเป็นทีม, การสื่อสาร, การปรับตัวและเรียนรู้อย่างต่อเนื่อง

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. อย่างน้อยหนึ่งอย่างจาก Kotlin, Swift, Flutter, React Native: ฝึกให้ถึงระดับใช้งานได้จริง
2. อย่างน้อยหนึ่งอย่างจาก Android development, iOS development: ฝึกให้ถึงระดับใช้งานได้จริง
3. Mobile UI development (การพัฒนาส่วนติดต่อผู้ใช้บนมือถือ): ฝึกให้ถึงระดับใช้งานได้จริง
4. REST API design (การออกแบบ REST API): ฝึกให้ถึงระดับพื้นฐาน
5. Debugging (การดีบักโปรแกรม): ฝึกให้ถึงระดับพื้นฐาน
6. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: สร้างแอปมือถือที่ดึงข้อมูลจาก API (เช่น แอปพยากรณ์อากาศ) ด้วย Flutter, Kotlin หรือ Swift และทดสอบบนเครื่องจริง

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): App store publishing, Unit and integration testing, UI design, Figma / design tools, Java, JavaScript
