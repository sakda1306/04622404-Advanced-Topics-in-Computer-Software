# วิศวกรข้อมูล (Data Engineer)

## Role description

สร้างและดูแล pipeline ที่เก็บ ย้าย และแปลงข้อมูล ให้ทีมวิเคราะห์และทีม AI มีข้อมูลที่ถูกต้องและพร้อมใช้

งานที่ทำเป็นประจำ: เขียน ETL pipeline, ออกแบบ data warehouse, ตั้งเวลาการทำงานของ job และตรวจคุณภาพข้อมูล

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การคิดวิเคราะห์, การสื่อสาร, การแก้ปัญหา

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. SQL: ฝึกให้ถึงระดับใช้งานได้จริง
2. อย่างน้อยหนึ่งอย่างจาก Python, Java, Scala: ฝึกให้ถึงระดับใช้งานได้จริง
3. ETL / data pipelines (กระบวนการ ETL และไปป์ไลน์ข้อมูล): ฝึกให้ถึงระดับใช้งานได้จริง
4. Data modeling (การออกแบบแบบจำลองข้อมูล): ฝึกให้ถึงระดับพื้นฐาน
5. Data warehousing (คลังข้อมูล (Data Warehouse)): ฝึกให้ถึงระดับพื้นฐาน
6. อย่างน้อยหนึ่งอย่างจาก AWS, Google Cloud, Microsoft Azure: ฝึกให้ถึงระดับพื้นฐาน
7. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับพื้นฐาน
8. ทำโปรเจกต์ฝึกหัด: สร้าง pipeline ที่ดึงข้อมูลจาก API ทุกวัน แปลงข้อมูลด้วย Python แล้วโหลดเข้า PostgreSQL หรือ BigQuery โดยตั้งเวลาด้วย Airflow

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Workflow orchestration (Airflow), Big data (Spark, Hadoop), NoSQL (MongoDB etc.), PostgreSQL, Message queues (Kafka, RabbitMQ), Docker / containers, Data governance and security
