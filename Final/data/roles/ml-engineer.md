# วิศวกรแมชชีนเลิร์นนิง (Machine Learning Engineer)

## Role description

นำโมเดล machine learning ไปใช้งานจริง สร้างระบบ train, deploy และดูแลโมเดลให้ทำงานเสถียรใน production

งานที่ทำเป็นประจำ: เตรียมข้อมูลและ train โมเดล, ปรับโค้ดให้มีประสิทธิภาพ, deploy โมเดลเป็น service และติดตามประสิทธิภาพของโมเดล

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การคิดวิเคราะห์, การแก้ปัญหา, การสื่อสาร, ความคิดสร้างสรรค์

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Python: ฝึกให้ถึงระดับใช้งานได้จริง
2. Machine learning (แมชชีนเลิร์นนิง): ฝึกให้ถึงระดับใช้งานได้จริง
3. อย่างน้อยหนึ่งอย่างจาก PyTorch, TensorFlow, scikit-learn: ฝึกให้ถึงระดับใช้งานได้จริง
4. Data structures and algorithms (โครงสร้างข้อมูลและอัลกอริทึม): ฝึกให้ถึงระดับใช้งานได้จริง
5. Mathematics (linear algebra, calculus) (คณิตศาสตร์ (พีชคณิตเชิงเส้น แคลคูลัส)): ฝึกให้ถึงระดับใช้งานได้จริง
6. Statistics (สถิติ): ฝึกให้ถึงระดับใช้งานได้จริง
7. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับพื้นฐาน
8. SQL: ฝึกให้ถึงระดับพื้นฐาน
9. ทำโปรเจกต์ฝึกหัด: train โมเดลด้วย scikit-learn หรือ PyTorch แล้ว deploy เป็น API ใน Docker พร้อม log ผลการทำนายเพื่อติดตามโมเดล

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): MLOps / model deployment, Docker / containers, Deep learning, AWS, Software architecture / system design, Data modeling
