# วิศวกรซอฟต์แวร์ (Software Engineer)

## Role description

ออกแบบ เขียน ทดสอบ และดูแลซอฟต์แวร์ตลอดวงจรการพัฒนา ทำงานกับทีมเพื่อแปลงความต้องการเป็นระบบที่ทำงานได้จริงและดูแลรักษาง่าย

งานที่ทำเป็นประจำ: เขียนโค้ดตาม requirement, รีวิวโค้ดของเพื่อนร่วมทีม, เขียน unit test, แก้บั๊ก และประชุมวางแผนงานแบบ sprint

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การแก้ปัญหา, การทำงานเป็นทีม, การสื่อสาร, การปรับตัวและเรียนรู้อย่างต่อเนื่อง

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. อย่างน้อยหนึ่งอย่างจาก Python, Java, JavaScript, C#, C++: ฝึกให้ถึงระดับใช้งานได้จริง
2. Data structures and algorithms (โครงสร้างข้อมูลและอัลกอริทึม): ฝึกให้ถึงระดับใช้งานได้จริง
3. Object-oriented programming (การเขียนโปรแกรมเชิงวัตถุ): ฝึกให้ถึงระดับใช้งานได้จริง
4. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับใช้งานได้จริง
5. Unit and integration testing (การทดสอบหน่วยและการทดสอบรวม): ฝึกให้ถึงระดับพื้นฐาน
6. SQL: ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: สร้างแอปเล็ก ๆ หนึ่งตัว (เช่น ระบบจัดการงาน) ที่มี unit test, ใช้ Git อย่างเป็นระบบ และเขียน README อธิบายการออกแบบ

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Software architecture / system design, REST API design, Agile / Scrum, Software development life cycle, Debugging, TypeScript, Docker / containers
