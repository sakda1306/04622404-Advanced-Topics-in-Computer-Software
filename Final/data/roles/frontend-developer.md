# นักพัฒนาฟรอนต์เอนด์ (Frontend Developer)

## Role description

พัฒนาส่วนติดต่อผู้ใช้ของเว็บแอป ให้ใช้งานง่าย สวยงามตามดีไซน์ เข้าถึงได้ และทำงานเร็ว

งานที่ทำเป็นประจำ: แปลงแบบ Figma เป็นคอมโพเนนต์, จัดการ state, เรียก API, ทดสอบการแสดงผลบนหลายเบราว์เซอร์ และปรับประสิทธิภาพหน้าเว็บ

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: ความละเอียดรอบคอบ, การสื่อสาร, ความคิดสร้างสรรค์, การทำงานเป็นทีม, การแก้ปัญหา

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. HTML: ฝึกให้ถึงระดับใช้งานได้จริง
2. CSS: ฝึกให้ถึงระดับใช้งานได้จริง
3. JavaScript: ฝึกให้ถึงระดับใช้งานได้จริง
4. อย่างน้อยหนึ่งอย่างจาก React, Vue.js, Angular: ฝึกให้ถึงระดับใช้งานได้จริง
5. Responsive design (การออกแบบเว็บแบบ Responsive): ฝึกให้ถึงระดับใช้งานได้จริง
6. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: สร้าง dashboard ด้วย React หรือ Vue ที่ดึงข้อมูลจาก API สาธารณะ รองรับมือถือ และผ่านการตรวจ accessibility เบื้องต้น

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): TypeScript, Next.js, Web accessibility, Web performance optimization, REST API design, Figma / design tools, UI design, Debugging, SEO
