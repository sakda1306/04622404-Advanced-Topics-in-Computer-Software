# นักวิเคราะห์ระบบธุรกิจอัจฉริยะ (Business Intelligence Analyst)

## Role description

แปลงข้อมูลขององค์กรเป็นรายงานและ dashboard ที่ช่วยตัดสินใจ ดูแลโมเดลข้อมูลและตัวชี้วัดทางธุรกิจ

งานที่ทำเป็นประจำ: คุยกับฝ่ายธุรกิจเพื่อกำหนด KPI, เขียน SQL, สร้างโมเดลข้อมูลและ dashboard และดูแลรายงานประจำ

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การสื่อสาร, การแก้ปัญหา, การคิดวิเคราะห์, ทักษะการนำเสนอ

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. SQL: ฝึกให้ถึงระดับใช้งานได้จริง
2. อย่างน้อยหนึ่งอย่างจาก Power BI, Tableau: ฝึกให้ถึงระดับใช้งานได้จริง
3. Business reporting (การจัดทำรายงานธุรกิจ): ฝึกให้ถึงระดับใช้งานได้จริง
4. Data modeling (การออกแบบแบบจำลองข้อมูล): ฝึกให้ถึงระดับพื้นฐาน
5. Business analysis (การวิเคราะห์ธุรกิจ): ฝึกให้ถึงระดับพื้นฐาน
6. Microsoft Excel / spreadsheets (Microsoft Excel / สเปรดชีต): ฝึกให้ถึงระดับใช้งานได้จริง
7. ทำโปรเจกต์ฝึกหัด: สร้าง dashboard ยอดขายใน Power BI จากข้อมูลหลายตาราง มี data model แบบ star schema และ KPI ที่อธิบายได้

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Data warehousing, ETL / data pipelines, Python, Statistics, Automation, Oracle Database
