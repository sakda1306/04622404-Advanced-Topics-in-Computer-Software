# เจ้าหน้าที่สนับสนุนด้านไอที (IT Support Specialist)

## Role description

ช่วยผู้ใช้ในองค์กรแก้ปัญหาคอมพิวเตอร์ ซอฟต์แวร์ และเครือข่าย เป็นด่านแรกที่ทำให้ทุกคนทำงานต่อได้

งานที่ทำเป็นประจำ: รับแจ้งปัญหาผ่าน help desk, ติดตั้งและซ่อมเครื่อง, ติดตั้งโปรแกรม, แก้ปัญหาเครือข่ายเบื้องต้น และสอนผู้ใช้

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การบริการลูกค้า, การสื่อสาร, ความอดทน, การแก้ปัญหา, การจัดระเบียบงาน

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Hardware installation and troubleshooting (การติดตั้งและแก้ไขปัญหาฮาร์ดแวร์): ฝึกให้ถึงระดับใช้งานได้จริง
2. Technical troubleshooting (การแก้ไขปัญหาทางเทคนิค): ฝึกให้ถึงระดับใช้งานได้จริง
3. Operating systems (ระบบปฏิบัติการ): ฝึกให้ถึงระดับใช้งานได้จริง
4. Software installation and configuration (การติดตั้งและตั้งค่าซอฟต์แวร์): ฝึกให้ถึงระดับใช้งานได้จริง
5. Help desk / ticketing (งาน Help desk และระบบตั๋วแจ้งปัญหา): ฝึกให้ถึงระดับพื้นฐาน
6. Computer networking (เครือข่ายคอมพิวเตอร์): ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: ประกอบหรือติดตั้งเครื่องใหม่ตั้งแต่ลง OS จนตั้งค่าเครือข่าย แล้วเขียนคู่มือแก้ปัญหาที่พบบ่อยสำหรับผู้ใช้

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Active Directory, Windows Server, macOS, ITIL / IT service management, CompTIA A+ / Network+, End-user training, Technical documentation, Cybersecurity
