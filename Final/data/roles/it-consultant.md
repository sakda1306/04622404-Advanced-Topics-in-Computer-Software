# ที่ปรึกษาด้านไอที (IT Consultant)

## Role description

ให้คำปรึกษาองค์กรเรื่องการใช้เทคโนโลยี วิเคราะห์ปัญหาทางธุรกิจ และเสนอแนวทางหรือระบบที่เหมาะสม

งานที่ทำเป็นประจำ: สัมภาษณ์ลูกค้าเพื่อเก็บ requirement, วิเคราะห์กระบวนการ, เปรียบเทียบทางเลือก, นำเสนอข้อเสนอ และติดตามการนำไปใช้

ระดับตำแหน่ง: มักต้องมีประสบการณ์ทำงานด้าน IT มาก่อน 2-3 ปี เด็กจบใหม่มักเริ่มจากตำแหน่งใกล้เคียงก่อน

ทักษะด้านบุคคลที่สำคัญ: การสื่อสาร, ทักษะมนุษยสัมพันธ์, การคิดเชิงวิพากษ์, การแก้ปัญหา, การปรับตัวและเรียนรู้อย่างต่อเนื่อง

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Requirements gathering and analysis (การเก็บและวิเคราะห์ความต้องการ): ฝึกให้ถึงระดับใช้งานได้จริง
2. Business analysis (การวิเคราะห์ธุรกิจ): ฝึกให้ถึงระดับใช้งานได้จริง
3. IT strategy and consulting (กลยุทธ์และการให้คำปรึกษาด้านไอที): ฝึกให้ถึงระดับพื้นฐาน
4. Project management (การบริหารโครงการ): ฝึกให้ถึงระดับพื้นฐาน
5. ERP / CRM systems (SAP, Salesforce) (ระบบ ERP / CRM (SAP, Salesforce)): ฝึกให้ถึงระดับพื้นฐาน
6. Cloud computing (คลาวด์คอมพิวติ้ง): ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: เลือกธุรกิจขนาดเล็กหนึ่งแห่ง วิเคราะห์กระบวนการทำงาน เสนอระบบ IT ที่เหมาะสมพร้อมเปรียบเทียบต้นทุน และทำสไลด์นำเสนอ

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Stakeholder management, Cybersecurity, PMP / PRINCE2 certification, Technical documentation, Hardware installation and troubleshooting
