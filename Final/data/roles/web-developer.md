# นักพัฒนาเว็บไซต์ (Web Developer)

## Role description

สร้างและดูแลเว็บไซต์ทั้งส่วนที่ผู้ใช้เห็นและส่วนหลังบ้านเบื้องต้น ให้เว็บแสดงผลถูกต้องทุกอุปกรณ์และโหลดเร็ว

งานที่ทำเป็นประจำ: พัฒนาหน้าเว็บจากแบบดีไซน์, เชื่อมต่อฟอร์มกับฝั่งเซิร์ฟเวอร์, ดูแล CMS และปรับเว็บให้รองรับมือถือและ SEO

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การแก้ปัญหา, การสื่อสาร, ความละเอียดรอบคอบ

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. HTML: ฝึกให้ถึงระดับใช้งานได้จริง
2. CSS: ฝึกให้ถึงระดับใช้งานได้จริง
3. JavaScript: ฝึกให้ถึงระดับใช้งานได้จริง
4. อย่างน้อยหนึ่งอย่างจาก PHP, Python, Ruby, Java, Node.js: ฝึกให้ถึงระดับพื้นฐาน
5. Responsive design (การออกแบบเว็บแบบ Responsive): ฝึกให้ถึงระดับพื้นฐาน
6. Git / version control (Git และการควบคุมเวอร์ชัน): ฝึกให้ถึงระดับพื้นฐาน
7. ทำโปรเจกต์ฝึกหัด: ทำเว็บไซต์ร้านค้าหรือพอร์ตโฟลิโอที่ responsive มีฟอร์มติดต่อที่บันทึกข้อมูลลงฐานข้อมูล แล้ว deploy ขึ้นออนไลน์

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): React, REST API design, CMS (WordPress etc.), SEO, Web design principles, UI design, SQL, Shell scripting (Bash/PowerShell)
