# นักวิทยาศาสตร์ข้อมูล (Data Scientist)

## Role description

ใช้สถิติและ machine learning หาข้อมูลเชิงลึกและสร้างโมเดลทำนาย เพื่อช่วยแก้ปัญหาทางธุรกิจ

งานที่ทำเป็นประจำ: สำรวจและเตรียมข้อมูล, สร้างและประเมินโมเดล, ทดลองหลายแนวทาง และสื่อสารผลให้คนที่ไม่ใช่สายเทคนิคเข้าใจ

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การคิดวิเคราะห์, การแก้ปัญหา, การสื่อสาร, การทำงานได้ด้วยตนเองและมีแรงจูงใจ, ความละเอียดรอบคอบ

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. อย่างน้อยหนึ่งอย่างจาก Python, R: ฝึกให้ถึงระดับใช้งานได้จริง
2. Statistics (สถิติ): ฝึกให้ถึงระดับใช้งานได้จริง
3. Machine learning (แมชชีนเลิร์นนิง): ฝึกให้ถึงระดับใช้งานได้จริง
4. Mathematics (linear algebra, calculus) (คณิตศาสตร์ (พีชคณิตเชิงเส้น แคลคูลัส)): ฝึกให้ถึงระดับใช้งานได้จริง
5. SQL: ฝึกให้ถึงระดับใช้งานได้จริง
6. pandas / NumPy: ฝึกให้ถึงระดับใช้งานได้จริง
7. Data visualization (การนำเสนอข้อมูลด้วยภาพ): ฝึกให้ถึงระดับพื้นฐาน
8. ทำโปรเจกต์ฝึกหัด: ทำโปรเจกต์ทำนายผล (เช่น ราคาบ้านหรือการยกเลิกบริการ) ใน Jupyter ตั้งแต่สำรวจข้อมูลจนประเมินโมเดล และสรุปผลเป็นภาษาธุรกิจ

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): scikit-learn, Deep learning, Predictive modeling, Technical documentation, Business reporting, Data management
