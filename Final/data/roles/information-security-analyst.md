# นักวิเคราะห์ความปลอดภัยสารสนเทศ (Information Security Analyst)

## Role description

ปกป้องระบบและข้อมูลขององค์กรจากภัยคุกคาม เฝ้าระวัง ตรวจหาช่องโหว่ และรับมือเหตุการณ์ด้านความปลอดภัย

งานที่ทำเป็นประจำ: ดู alert จากระบบเฝ้าระวัง, สแกนหาช่องโหว่, ตรวจ log, ตอบสนองเหตุการณ์ และเขียนรายงานความเสี่ยง

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การคิดวิเคราะห์, การแก้ปัญหา, การตัดสินใจ, การสื่อสาร, การปรับตัวและเรียนรู้อย่างต่อเนื่อง

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. Cybersecurity (ความมั่นคงปลอดภัยไซเบอร์): ฝึกให้ถึงระดับใช้งานได้จริง
2. Computer networking (เครือข่ายคอมพิวเตอร์): ฝึกให้ถึงระดับใช้งานได้จริง
3. TCP/IP, DNS, DHCP: ฝึกให้ถึงระดับใช้งานได้จริง
4. Vulnerability assessment / penetration testing (การประเมินช่องโหว่และทดสอบเจาะระบบ): ฝึกให้ถึงระดับพื้นฐาน
5. Firewalls (ไฟร์วอลล์): ฝึกให้ถึงระดับพื้นฐาน
6. Incident response (การตอบสนองต่อเหตุการณ์ด้านความปลอดภัย): ฝึกให้ถึงระดับพื้นฐาน
7. Linux: ฝึกให้ถึงระดับพื้นฐาน
8. Monitoring and logging (การเฝ้าระวังและบันทึกระบบ): ฝึกให้ถึงระดับพื้นฐาน
9. ทำโปรเจกต์ฝึกหัด: ตั้ง lab ด้วย virtual machine แล้วสแกนช่องโหว่ วิเคราะห์ log และเขียนรายงานพร้อมวิธีแก้ หรือฝึกโจทย์บน TryHackMe

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): SIEM / security monitoring, Security certifications (CompTIA Security+, CISSP, CEH), Encryption, Risk management and compliance, Authentication and access control, Network security, Cloud computing, Routing and switching
