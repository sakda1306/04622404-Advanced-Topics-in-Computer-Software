# ผู้ดูแลระบบ (Systems Administrator)

## Role description

ดูแลเซิร์ฟเวอร์และระบบปฏิบัติการขององค์กร ติดตั้ง ตั้งค่า อัปเดต สำรองข้อมูล และแก้ปัญหาให้ระบบพร้อมใช้งาน

งานที่ทำเป็นประจำ: ติดตั้งและอัปเดตเซิร์ฟเวอร์, จัดการผู้ใช้และสิทธิ์, ดูแล virtual machine, สำรองข้อมูล และเขียนสคริปต์ทำงานอัตโนมัติ

ระดับตำแหน่ง: เหมาะกับผู้เริ่มต้นและเด็กจบใหม่

ทักษะด้านบุคคลที่สำคัญ: การแก้ปัญหา, การคิดเชิงกลยุทธ์, การสื่อสาร

## Learning path

เรียงตามความสำคัญต่อการได้งานในตำแหน่งนี้:

1. อย่างน้อยหนึ่งอย่างจาก Linux, Windows Server: ฝึกให้ถึงระดับใช้งานได้จริง
2. Server administration (การดูแลเซิร์ฟเวอร์): ฝึกให้ถึงระดับใช้งานได้จริง
3. Operating systems (ระบบปฏิบัติการ): ฝึกให้ถึงระดับใช้งานได้จริง
4. Computer networking (เครือข่ายคอมพิวเตอร์): ฝึกให้ถึงระดับพื้นฐาน
5. Virtualization (VMware, Hyper-V) (เวอร์ชวลไลเซชัน): ฝึกให้ถึงระดับพื้นฐาน
6. Backup and disaster recovery (การสำรองและกู้คืนข้อมูล): ฝึกให้ถึงระดับพื้นฐาน
7. Shell scripting (Bash/PowerShell) (การเขียนสคริปต์เชลล์): ฝึกให้ถึงระดับพื้นฐาน
8. ทำโปรเจกต์ฝึกหัด: ตั้งเซิร์ฟเวอร์ Linux บน virtual machine ติดตั้ง web server ตั้งผู้ใช้และสิทธิ์ และเขียน bash script สำรองข้อมูลทุกวัน

ทักษะที่ช่วยให้โดดเด่นขึ้น (ไม่บังคับ): Active Directory, Cloud computing, Monitoring and logging, Automation, Device management, Cybersecurity, Hardware installation and troubleshooting
